# Contributing

Thanks for your interest in contributing to this project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/Hospital-Management-System.git`
3. Set up the project following the [README](README.md#quick-start)

## Development Workflow

- Create a feature branch from `main`: `git checkout -b feat/your-feature`
- Make your changes
- Ensure the backend compiles: `cd backend && mvn compile`
- Ensure the frontend builds: `cd frontend && npm run build`
- Commit with a clear message describing the change
- Push and open a pull request

## Code Style

- Java: follow standard Spring Boot conventions
- React: use functional components with hooks, JSX, Tailwind CSS utility classes
- Avoid adding comments unless the logic is non-obvious

## Pull Request Guidelines

- Keep PRs focused on a single concern
- Link any related issues
- Describe what the change does and why
- Ensure no secrets or credentials are included

## Reporting Issues

Open an issue at https://github.com/kalamkarkrushna/Hospital-Management-System/issues
